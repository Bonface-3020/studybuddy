# StudyBuddy — Student Study Planner

A small team project for learning Git and GitHub collaboration.

## Goal
Build a simple study planner where a student can view tasks, add a task, mark a task complete, and see a progress summary.

## Team roles
- **Elizabeth — Frontend:** HTML, CSS, Bootstrap and JavaScript in `frontend/`.
- **Pio — Task logic:** Python task functions in `backend/`.
- **Mary — Progress summary:** Python progress calculations in `analytics/`.

## Keep the first version small
No login, database, machine learning or deployment is required. The frontend can use sample data, while the Python modules are built and tested separately.

## Team workflow
1. Read your assigned GitHub Issue.
2. Update your local `main` branch.
3. Create a feature branch.
4. Make and test your change.
5. Commit and push the branch.
6. Open a pull request and link the issue.
7. Ask a sibling to review it.
8. Merge after review and any required fixes.

Do not push feature work directly to `main`.

## Definition of done
The issue's acceptance criteria are met, the code runs, testing is done, the pull request explains the change, and at least one teammate has reviewed it.
